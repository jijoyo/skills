# Capacitor Fullscreen Alarm Dialog

Buy on Agensi: https://agensi.io/skills/capacitor-fullscreen-alarm-dialog · $19.99

A fullscreen alarm dialog pattern for Capacitor apps that behaves like a real
alarm clock: turns the screen on, rides over Do Not Disturb, and demands
attention — the difference between a medical reminder that was *seen* and one
that died silently behind a silenced notification.

## What it does

- Initiate a turn-screen-on, show-over-lockscreen, fullscreen-intent-style
  alarm dialog from native Android through Capacitor.
- An APK/install checklist that demystifies the Android build steps people
  trip on (gradle wiring, permissions, release-keystore sanity).
- Troubleshooting recipes for the classic failure modes: DND eating the
  dialog, OEM battery-optimizations suppressing it, and debug vs release
  behavior differences.

## Who it is for

Any Capacitor/Ionic app where a missed alert is unacceptable — medication
reminders, care apps, safety notifications.

## Honest limits

Android-focused (iOS has its own constraints, documented as such); OEM
battery quirks vary by vendor and are treated explicitly, not hand-waved.

Proven in a shipped healthcare app used daily — where "the alarm ran but the
screen stayed off" was not an acceptable bug.
